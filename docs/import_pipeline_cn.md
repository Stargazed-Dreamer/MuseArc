# 导入流程与分支（当前实现）

## 1. 扫描阶段
1. 扫描导入目录，区分音频文件与歌词文件。
2. 读取断点续传状态（若存在），已处理文件直接跳过。
3. 初始化本批次文件状态：待处理、处理中、已归档、待审查、已跳过。

## 2. 音频阶段
1. 路径级快速排除（进入重处理前）：
   - 源路径已在库内（含已删除）。
   - 源路径命中历史“已跳过歌曲路径”索引。
   - 源路径已在待审查队列中。
2. 音频探测（时长、采样率、码率、标签等），失败进入文件异常审查。
   - 元数据解析优先级：`ID3/容器标签 > 文件名推断`。
   - 标签疑似乱码时会尝试多编码修复（GB18030/Big5/Shift-JIS 等）。
3. 低时长过滤（疑似试听/哑文件）进入文件异常审查。
4. 响度归一（-14 LUFS）+ 指纹提取，失败进入文件异常审查。
5. 指纹重复决策：
   - 保留已有：跳过新文件。
   - 待审查：进入歌曲审查组（延后入库）。
   - 其它分支：继续归档入库。
6. 归档复制时同步计算 `source_sha256`：
   - 命中未删除曲目：直接跳过。
   - 命中已删除曲目：进入“已删除歌曲重新导入”审查。
7. 任何“已跳过歌曲”都会记录其源路径，用于后续导入快速排除。
8. 重复替换时默认优先高质量来源：
   - 综合格式等级（FLAC/WAV/APE > ALAC > AAC/OPUS/OGG > MP3 等）与质量分；
   - 对缺失比特率的 VBR 格式会用 `文件大小/时长` 估算，减少 MP3 误优先。

## 3. 歌词阶段
1. 路径级快速排除：
   - 命中历史歌词路径索引（已处理过）。
   - 源路径已在待审查队列中。
2. 读取歌词并做 HTML 反转义。
3. 纯音乐占位歌词：
   - 跳过歌词导入；
   - 尝试按文件名匹配本批次歌曲，命中则把歌曲标记为 `instrumental`。
4. 文本哈希去重：
   - 命中已删除歌词：进入“已删除歌词重新导入”审查。
   - 命中未删除歌词：直接跳过（不再重复生成待审查项）。
5. 新歌词写入库后执行歌曲匹配：
   - 先尝试匹配“本批次歌曲”；
   - 若不足以自动判定，再尝试“全库歌曲”；
   - 自动匹配失败则进入歌词审查，并给出建议歌曲（本批次优先，全库补充）。

## 4. 待审查去重原则
1. 同一源路径若已在 pending 审查队列，后续导入直接跳过，不再重复生成审查项。
2. 歌词命中库内相同文本时直接跳过，避免重复审查。
3. 歌词审查页可将“预览中的两条歌词”执行时间轴合并：合并后文本写回前者、后者移入回收区，并记录撤回快照。

## 5. 取消与恢复
1. 取消可选：
   - 保留已处理进度后停止；
   - 全部回退后停止。
2. 进度保留模式可从“继续未完成导入”恢复。

## 6. 关键持久化索引
1. `manifests/imports/skipped_audio_paths.json`：历史跳过歌曲路径。
2. `manifests/imports/seen_lyrics_paths.json`：历史已处理歌词路径。

## 7. 导入后批量修复工具
1. 菜单栏 `更多 -> 使用ID3和歌词更新歌曲元信息`。
2. 可选择一个全量筛选工作批量处理：
   - 有 ID3 时直接覆盖；
   - 无 ID3 时尝试 `文件名 + 歌词元数据` 兜底；
   - 均缺失则跳过并给出原因。

## 8. 指纹相似度分段规则（2026-04 更新）

导入去重决策当前使用以下相似度分段（`score` 范围 `0~1`）：

- `0.50 ~ 1.00`：判定为“同一歌曲”区间。进入重复决策，按音质/格式优先保留更优版本。
- `0.30 ~ 0.50`：判定为“人工审查区间”。不自动覆盖，进入待审查队列。
- `0.10 ~ 0.30`：判定为“同曲不同编配提示区间”（常见原版/伴奏）。默认保留两者，并写入变体关系提示。
- `0.01 ~ 0.10`：判定为“翻唱提示区间”（常见异演唱者版本）。默认保留两者，并写入变体关系提示。
- `< 0.01`：判定为“低相关区间”，默认按不同歌曲处理。

补充说明：

- 若标题（去尾括号后）+ 时长（10 秒内）高度一致，即使相似度不高，也会进入人工审查，避免漏判。
- 上述区间由运行时配置 `thresholds` 驱动：`duplicate_high`、`duplicate_review`、`duplicate_instrumental_hint`、`duplicate_cover_hint`。
