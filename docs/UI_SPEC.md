# UI 规格（待实现）

## 1. 总体信息架构

主窗口：`打开音乐库 -> 数据库搜索界面`

左侧边栏建议：

1. 全部歌曲
2. 待人工审查
3. 歌单管理
4. 文件管理
5. 导入历史
6. 回收站
7. 设置

主区建议：

- 顶部：全局搜索、筛选条件、批量操作条、多选模式开关
- 中部：歌曲列表/分组视图
- 底部：状态栏（选中数量、过滤命中、当前任务）

歌曲上下文菜单：

- 播放
- 导出
- 删除/移动
- 绑定歌词
- 标记版本（Live/Remix/等）

## 1.1 内置播放器（简易）

- 顶级窗口底部固定一行控制栏（默认隐藏）。
- 控件：音量条、开始/暂停、可拖动进度条、上一首、下一首、关闭。
- 行为：
  - 任意界面触发播放时，先清空播放器队列，再按当前选择重建队列。
  - 歌单管理页提供“播放歌单”，按当前歌单顺序入队。
  - 关闭按钮会停止播放并隐藏控制栏（不做后台播放）。

## 2. 待人工审查页

按类型分组：

- 疑似重复
- 歌词待确认
- 文件异常（损坏/过短/伪装）
- 元数据冲突

每条审查项应提供：

- 自动建议
- 快速操作（接受建议 / 驳回 / 延后）
- 对比视图（波形/元数据/歌词前十行）

## 3. 文件管理页

支持：

- 按导入来源树浏览
- 重命名、移动、批量改标签
- 显示“库内文件路径（ID路径）”与“逻辑显示名”双视图

## 4. 多选模式交互契约

## 4.1 状态定义

- `NormalMode`
- `MultiSelectMode`

状态变量：

- `selectedSet`: 当前选中集合
- `anchorItem`: 区间操作锚点
- `focusItem`: 键盘焦点项
- `savedSelections`: 最多 5 个历史选择快照（FIFO）

## 4.2 普通模式

- 鼠标单击：单选当前项（清空其它选中）
- 双击：打开详情/默认动作
- 拖动：框选范围内项
- Ctrl：离散增减选
- Shift：连续区间选
- Enter：对焦点项执行默认动作
- Delete：删除当前选中

## 4.3 多选模式

鼠标：

- 左键单击：反选当前项，并将 `anchorItem` 更新为当前项
- 左键拖动：反选拖动覆盖范围，并将 `anchorItem` 更新为拖动终点
- 右键单击/拖动：先执行同样反选逻辑，再弹出已选项菜单

键盘：

- 上/下：仅移动 `focusItem`，不改变 `selectedSet`
- 左/右：70% 视窗翻页（保留重叠项）
- Enter/Space：等价于鼠标左键单击（反选 `focusItem`）
- Shift+Enter/Shift+Space：等价于拖动反选，区间 = `anchorItem` 到 `focusItem`
- Ctrl+S：保存当前 `selectedSet` 到 `savedSelections`

自动保存规则：

- 退出多选模式时，如果 `selectedSet` > 10 且本次未手动保存，触发强制保存。
- 强制保存阈值需放入设置可配置。

## 4.4 对照表

| 操作 | 普通模式 | 多选模式 |
|---|---|---|
| 鼠标单击 | 单选 | 反选当前项 |
| 拖动选择 | 选中范围内所有项 | 反选范围内项 |
| Shift选择 | 连续区域选择 | 累加反选区间 |
| Ctrl选择 | 离散多选 | 无效 |
| 键盘导航 | 改变当前选中项 | 保持已选项，仅移动焦点 |

## 5. 可实现组件建议

- `SelectionController`：封装模式状态机与所有选中逻辑
- `ReviewQueuePanel`：审查项列表 + 决策按钮
- `TrackTable`：虚拟列表（大库性能关键）
- `ActionBar`：批量导出/删除/移动/绑定歌词
- `FilterBar`：规则筛选（版本类型、是否有歌词、质量分、异常标记）

## 6. 性能建议

- 列表采用虚拟滚动 + 分页查询。
- 搜索支持增量结果和取消前次查询。
- 审查页支持批量确认与撤销。
